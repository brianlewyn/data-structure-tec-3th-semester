# Búsqueda Binaria

La búsqueda binaria es un algoritmo eficiente que trabaja dividiendo el arreglo a la mitad en cada paso. Requiere que el arreglo esté previamente ordenado y descarta la mitad de los elementos en cada comparación.

## Requisitos
- JDK 8 o superior
- Código desarrollado y probado con JDK 27 (2026-09-15).

## Clonar
```
git clone https://github.com/brianlewyn/data-structure-tec-3th-semester.git
cd data-structure-tec-3th-semester
```

## Compilar
```
javac Unidad6/BusquedaBinaria/PracticaBusquedaBinaria.java
```

## Ejecutar
```
java Unidad6.BusquedaBinaria.PracticaBusquedaBinaria
```
