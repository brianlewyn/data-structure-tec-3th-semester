# Búsqueda Secuencial

La búsqueda secuencial (o lineal) es el método de búsqueda más simple. Consiste en recorrer el arreglo elemento por elemento, desde el inicio hasta el final, comparando cada valor con la clave buscada hasta encontrarla o agotar todos los elementos.

## Requisitos
- JDK 8 o superior
- Código desarrollado y probado con JDK 27 (2026-09-15).

## Clonar
```
git clone https://github.com/brianlewyn/data-structure-tec-3th-semester.git
cd data-structure-tec-3th-semester
```

## Compilar
```
javac Unidad6/BusquedaSecuencial/PracticaBusquedaSecuencial.java
```

## Ejecutar
```
java Unidad6.BusquedaSecuencial.PracticaBusquedaSecuencial
```
